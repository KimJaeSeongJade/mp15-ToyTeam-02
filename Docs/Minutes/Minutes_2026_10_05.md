## ✅ 3. 결정 사항 

### 1. 열차 관련 시각 효과 및 연출 제안

- 담당자: 김영규

- 기한: 필수 구현 사항 기한 까지

- `언레일드2` 및 구현 테스트 중 피드백 받은 부분을 개선하기 위해 추가 UI구현

    - 제작칸에서 레일 제작시 진행도를 표시하는 UI 추가

    - 맵의 배치된 도구를 직관적으로 확인 할 수 있는 아이콘


### 2. 프로젝트 구현 볼륨 재설정

- 담당자: 팀 전원

- 기한: 프로젝트 마감 기한까지

- 구현 완료된 여러 기능을 병합함에 따라 다양한 충돌 및 버그 상황 발생

- 2개의 기능 구현을 후순위로 배정

    - 자동 상호작용 기능(플레이어가 소지한 동일한 아이템 개수 자동 중첩)

    - 화물칸에서 재료를 다시 꺼내는 기능


### 3. 구현 담당 재조정 

- 담당자: 서희수, 이정한

- 기한: 프로젝트 마감 기한까지

- UI 업무의 과중을 분산하기 위해 튜토리얼 스테이지 구현 업무 이관
