# 레일 설치/해제 및 형태 자동 설정 기능

## 📝 1. 기능 개요

### 1.1. 기능 정의

- 인접한 레일 간의 배치 상태를 파악하 레일의 외형 및 회전 각도를 자동으로 설정하는 기능

- 레일 프리팹은 직선 및 곡선 모양 2가지 형태의 메쉬로 구성하고, 이를 상태에 맞게 회전시킴

### 1.2. 구현 목표
- 맵에 레일이 배치 될 때 꺾이는 구간(곡선)을 자동으로 감지해 자연스럽게 연결된 모양을 연출하기

- 제거할 때도 레일의 상태(타일 또는 아이템 인지)를 전환하고, 

  변경된 레일 연결 상황을 업데이트해 자동으로 모양이 변경 되기

### 1.3. 클래스 설명 
- `Rail.cs`: 
    - 레일 오브젝트의 중첩 수량, 상태(아이템 / 타일 전환), 테두리 표시를 관리
    - 미리 모양을 정리한 외형 Enum에 따라 프리팹 활성화 및 회전을 적용
- `RailManager.cs`: 
    - `LinkedList<Rail>` 구조를 활용해 레일 배치 가능 한지 판단 
    - "이전 - 현재 - 다음 레일" 간의 상대 좌표 변화를 분석하여 `RailShape`를 선정

## 🚨 3. 주요 이슈 및 디버깅 사례

### 3.1. 레일 회수 시 중간 / 이전 레일의 모양 미갱신 문제

- **발생 문제**: 플레이어가 마지막으로 설치된 레일을 철거(`RemoveLastRailway`)할 때, 
  
  남아있는 새로운 마지막 레일의 형태가 곡선에서 직선으로 원상복구되지 않거나, 잘못된 방향을 유지하는 현상 발생

- **원인 분석**: 레일 설치 시에는 "새 레일"만 계산하여 추가했기 때문에, 

  회수 시 리스트의 Node가 제거된 후의 끝 노드(`Rails.Last`)에 대한 연결 상태 재계산 로직이 누락

- **해결 방법**

    - `UpdateRailwayShape()` 메서드를 `AddRailway()`(레일 설치)뿐만 아니라 `RemoveLastRailway()` 처리 시(레일 제거)에도 호출하도록 수정

    - 삭제 후 `Rails.Last`가 된 레일의 `Next` 노드가 `null`임을 판별한뒤,  이전 레일 방향에 맞는 형태로 자동 전환되도록 구현

### 3.2. 곡선 레일 프리팹의 회전 이슈

- **발생 문제**: 곡선 레일 적용 시, Inspector 상에서 90도 단위로 회전시켰음에도 모델이 어긋나는 현상 발생

- **원인 분석**: 프리팹의 메쉬 기준축이 Y축 상립이 아닌 X축 -90도로 누워있는 구조였음

- **해결 방법**: `ChangeRailShape()` 내 곡선 레일 처리 시, 기준 각도인 `x: -90`을 기본으로 지정하고 Y축을 90도 단위(0°, 90°, 180°, 270°)로 회전시키는 방식 적용
