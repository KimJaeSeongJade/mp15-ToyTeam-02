# 팀8호선 기능명세

## 필수 구현 요소

### 1. 게임승리 / 패배조건

#### 승리
- 열차가 목표 지점까지 도달
#### 패배
- 선로가 없어 열차가 일정시간 동안 멈춘 경우

### 2. 열차
- 열차는 플레이의 개입 없이 선로를 따라 자동 진행
- 열차는 오직 선로를 따라서만 이동함
- 씬의 카메라는 열차를 따라 이동(수평 이동 시)
- 열차는 과열될 시 각칸이 개별적으로 기능 정지함

### 2-1. 화물차
- 재료(= 선로를 만드는 재료) 보관하는 차량
- 제작차와 함께 재료를 선로의 부품으로 변환
- 제작차가 요청하면 재료를 전달함
- 플레이어가 상호작용하여 재료를 화물차안에 탑재
- 재료를 탑재할 수 있는 상한이 정해져 있음
- 상한을 초과할 경우 화물차안에 재료 보관 불가

### 2-2. 제작차
- `화물차`에 재료(`목재`와 `철`)이 있다면 일정 시간마다 선로를 제작
- 플레이어가 상호작용하면 생산된 선로를 얻을 수 있음
- 완성된 선로를 보관해놓을 수 있는 상한이 정해져 있음
- 상한을 초과할 경우 제작차의 선로 생산 중단

### 3. 자원 및 재료
- 플레이어의 상호작용을 통해 `자원`을 `재료`로 변환시킴

1) 자원
- 스테이지에 배치되며, 플레이어와 상호작용 가능 (자원 수집)
- 플레이어가 상호작용할 때마다 자원(= 돌과 나무)가 단계별로 작아지며, 3번 상호작용하면 파괴됨

2) 재료
- 자원이 파괴된 자리에 자원에 따른 재료가 남겨짐(나무는 목재, 돌은 철로)
- 플레이어는 재료와 상호작용하여 재료를 운반할 수 있음
- 재료 겹치기: 플레이어가 재료를 들고있는 상태에서, 재료가 이미 존재한 위치에 내려놓으면 재료는 합쳐짐
- 재료는 총 3개 까지 겹쳐짐

### 4. 작업 도구
- 곡괭이 / 도끼 / 양동이 3개로 구성
- 플레이어는 상호작용을 통해 작업도구를 장착하거나 맵에 내려놓을 수 있음
- 각 작업도구는 맵에 1개씩만 존재
- 각 작업도구는 특정 자원만 수집할 수 있음
- 곡괭이 - 돌 / 도끼 - 나무 / 양동이 - 물 

### 5. 선로
- 직진 선로와 방향을 바꾸는 선로 2가지 형태가 존재
- 방향은 바꾸는 선로는 상하좌우로 열차의 진행방향을 변경함
- 플레이어는 선로와 상호작용 하여 손에 들거나 맵에 배치할 수 있음
- 열차가 이미 지나친 선로는 플레이어와 상호작용 불가능 

### 6. 플레이어
1) 이동
- 상하좌우 이동가능
- 플레이어가 이동할 수 없는 타일이 존재(물 등)

2) 상호작용
- 작업도구 / 재료 / 열차와 상호작용 가능
- 플레이어는 한번에 하나의 도구만 장착할 수 있음
- 다른 작업도구를 장착하면 기존에 장착한 작업도구는 맵에 남겨짐
- 플레이어가 한번에 운반할 수 있는 재료와 선로의 상한이 정해져 있음

### 7. 역
- 선로를 이어 열차가 도착해야할 목표지점
- 열차가 역에 도착하면 게임 승리

### 8. 스테이지
- 총 2개의 스테이지로 구성
- 게임안내를 도와줄 튜토리얼 스테이지 1개
- 본격적인 게임성이 구현된 메인 스테이지 1개

## 추가구현 고려 사항
### 1. 탱크차(열차) 및 과열 시스템
- 열차의 과열 상태를 감지
- 누적시간에 따라 온도가 높아지며, 점점 빨갛게 색깔 변화
- 플레이어가 냉각하는 상호작용을 통해 온도를 낮출 수 있음
- 과열이 일정시간 이상 유지되면, 화재가 발생
- 화재가 발생하면 근접한 화물열차로 불이 번짐
- 패배조건으로 `열차 전체에 불이 번진 후 일정시간이 경과한 경우` 추가

### 1. 볼트
- 열차를 업그레이드시키는 `재료`
- 맵에 배치되어있으며, 플레이어와 상호작용하여 운반 가능
- 볼트를 소지한채로 열차와 상호작용하면 각 열차의 기능에 맞게 성능이 향상됨
    - 제작차: 선로 제작속도 향상
    - 화물차: 재료 보관용량 증가

### 2. 추가 열차
- 과급차: 일정시간마다 `활성상태`로 진입하며 `활성상태`로 진입하면 인접한 열차가 정해진 시간동안 업그레이드 효과를 적용받음
- 변환차: 재료를 1:1비율로 변환시켜줌(나무>철, 철>나무), 쿨타임 존재

### 3.방해물(= 적)
- 고정형과 이동형으로 구분

1) 고정형
    - 위치가 고정되어 열차와 플레이어의 이동에만 제약을 거는 방해물
2) 이동형
    - 일정 범위를 돌아다니며 플레이어를 방해함
    - 플레이어의 이동에 제약을 검(장애물, 이동속도 저하 등)
    - 자원을 파괴하거나 플레이어가 재료를 운반 할때 이를 방해함
    - 플레이어가 상호작용하면 방해물 제거 가능 

### 4. 추가 스테이지
- `3-1. 고정형 방해물`이 매치된 추가 맵
- 무한 모드: 목표지점인 `역`이 없고, 게임오버 되기 까지 계속해서 선로를 만들 수 있는 맵 
    - 자동으로 맵 생성 (도입 고려 - 파동 함수 붕괴 알고리즘)

### 5. 다리
- 열차와 플레이어가 이동할 수 없는 `물`타일에 설치 가능 
- 플레이어 이동 및 선로를 설치할 수 있게 만들어 주는 요소
